# Arcade World Cups (AWC)
Arcade World Cups is an arcade-style football game developed in Godot. The project focuses on fast-paced gameplay, short matches and accessible controls, inspired by classic arcade football titles.
A playable build is available on itch.io

## Play the game
https://nicosoftarg.itch.io/arcade-world-cups

## Project status
Playable prototype.
The game is under active development and iteration.

## Implemented systems
- Player movement and input handling
- Basic match flow and game state management
- Arcade-oriented control responsiveness
- Simple AI behaviors for opponents
- Match setup and progression logic

## Tech & Tools
- Engine: Godot 4.4
- Lenguage: GDScript
- Platform: PC / Android
- Role: Solo game programmer and designer
- Testing: Tested on real Android devices during development

## Developer focus
This project showcases skills related to:
- Gameplay programming
- Game feel and responsiveness
- Iterate prototyping
- Scope control for small-to-mid size projects

### Development notes

This project is developed iteratively with a gameplay-first approach. Some systems are still experimental and will be refactored once their behavior is a fully validated.

## What I would improve next

- Performance optimizations and profiling on Android devices
- Refinement of touch input and on-screen controls
- More advanced AI behaviors while maintaining arcade pacing
- Additional game mode and match variations

## Notes
Arcade World Cups is intentionally designed as an arcade experience. It is not a football simulator or management game.
